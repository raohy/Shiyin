拾音安装说明

macOS 会议记录 app：录音、实时逐字稿、说话者识别、AI 会议记录

1. 安装

把 DMG 里的「拾音」拖到旁边的 Applications（应用程序）文件夹。

2. 第一次打开

拾音没有经过 Apple 公证，第一次打开时 macOS 会挡下来，显示「无法验证开发者」或「Apple 无法检查是否包含恶意软件」。请照下面的步骤放行（只要做一次）：

  1. 先在「应用程序」里双击拾音，看到警告后按「完成」或「好」。
  2. 打开「系统设置 → 隐私与安全性」，往下卷到「安全性」。
  3. 会看到「已阻挡『拾音』」，按旁边的「仍要打开」，再输入密码确认。

熟悉终端的话，也可以执行：xattr -dr com.apple.quarantine /Applications/Shiyin.app

3. 首次使用引导

打开后会出现引导，依序：允许麦克风、下载转录模型（约 1.7 GB，只需要一次）、选择整理会议记录的工具。

  • 整理工具：已经安装并登录 Claude Code（claude）或 Codex（codex）的话直接选；没有的话可以填 Anthropic 或 OpenAI 的 API key，或先选「不整理」只要逐字稿。
  • 会议语言：中文或英文。新的会议用设置里的默认语言，录音、导入时或之后都可以个别改。
  • 全域快捷键：在任何 app 里按 ⌃⌥⌘R 都能开始或停止录音。
  • 录在线会议：录音来源选「麦克风＋电脑声音（在线会议）」。第一次录的时候 macOS 会询问「录制系统音频」，请按允许；如果不小心拒绝了，到「系统设置 → 隐私与安全性 → 录制屏幕与系统录音」打开拾音。

4. 系统需求

  • Apple Silicon（M1 以上）的 Mac，macOS 26 以上
  • 内存 8 GB 以上，磁盘空间约 2 GB（加上录音）

5. 隐私

录音、转录、说话者识别都在你的 Mac 上完成，录音不会上传。整理会议记录时，只会把逐字稿文字送到你选的 AI 服务。

6. 更新

发布的人有设置更新网址的话，拾音会自己检查新版，询问你之后自动下载、验证并重新打开；也可以从「拾音」菜单选「检查更新…」。

没有自动更新时，下载新版 DMG，把新的拾音拖进「应用程序」取代旧的即可。两种方式的会议资料都会保留。
