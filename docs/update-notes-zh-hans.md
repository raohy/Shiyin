# 拾音 Mac 简体中文适配更新说明

更新日期：2026 年 11 月 10 日

适用版本：基于 Mac 4.7.0，构建号 24 的本地测试版

本次更新将 Mac 版的中文界面、中文转录结果、AI 整理提示词和导出标签统一适配为简体中文，并调整为更符合大陆用户习惯的用词。现有的录音、转录、会议记录、提问和导出功能都沿用原来的使用流程。

## 主要功能调整

| 功能 | 本次调整 | 使用效果 |
|---|---|---|
| 中文界面 | 菜单、按钮、设置、首次使用引导、通知、错误提示和权限说明转为简体 | 主要操作界面的中文显示统一为简体；英文界面继续保留 |
| 正式转录 | 中文和粤语转录结果在流程结束时统一转简体，并转换部分台湾用词 | 例如“软体”转为“软件”、“预设”转为“默认”；不同转录引擎共用输出转换逻辑 |
| 实时逐字稿 | 中文识别区域调整为中国大陆；实时暂定文字和定稿文字接入简体转换 | 录音时的实时中文显示按简体配置处理，真实麦克风效果仍待验证 |
| AI 会议记录 | 整理、草稿和校稿提示词改为简体；生成记录在保存前再次统一字形 | 模型偶尔返回繁体时，标题、摘要、决议、待办、议题、自定义段落和待确认问题也会转为简体 |
| 会议提问和辅助建议 | 单场及跨会议提问的中文回答、逐字稿校正说明、说话者判断理由明确要求使用简体中文 | 中文回答和建议遵循简体输出要求；引文和需要精确匹配的原文继续保留原样 |
| 心智图和导出 | 心智图复用新生成的简体会议记录；导出的中文标题和标签改为简体 | 新生成的记录可继续用于心智图、Markdown、Word、PDF 和 HTML 输出 |
| 中文字体 | 界面通用标题及中文会议内容使用简体字形配置，中文正文和标题采用 PingFang SC、Songti SC 等字体 | 中文显示和导出采用简体字体配置，减少字体字形不一致的问题 |
| 参考文件识别 | 中文参考文件的 OCR 优先使用简体中文识别配置 | 扫描文件和图片中的中文按简体配置优先识别 |
| 更新提示和使用文档 | 更新弹窗中的旧版中文说明在显示时转简体；README、DMG 安装说明源文件同步调整 | 更新提示和使用说明的中文用词与本次适配保持一致 |

## 兼容性处理

已有会议内容保留原样。需要将旧会议改为简体时，可重新转录音频，或刷新会议记录；两项操作分别更新逐字稿和整理结果。用户笔记、导入原文及引用内容不会被批量改写。

修复了批量转换带来的旧数据兼容问题：旧版繁体默认说话者名称继续被识别为默认名称，避免升级后将这类标签误当作真实人名，用于声纹或说话者处理。

日文、英文和韩文会议继续使用各自的提示词、模板及输出规则。自动回归已确认相关语言内容保持一致。

## 已完成的验证

- Mac DEBUG 应用构建及资源打包通过，简体本地化资源和新增转换字表已打包。
- 本地化检查通过，共检查 1133 条界面字符串，没有发现缺少英文翻译或漏查表的界面中文。
- 23 项简体输出回归检查通过，覆盖常见用词、混合中英文、会议记录字段、非中文内容保留及更新说明显示。
- 使用合成中文音频运行实际 Breeze 转录，得到简体逐字稿。
- 使用本地假模型故意返回繁体会议记录，确认保存后转为简体，并实际验证 Markdown、Word、PDF 导出内容。
- 标准答案导出成功生成 367 份文件；其中 144 份日文、英文、韩文相关内容与原标准答案一致，HTML 的差异仅为中文代码注释。
- 旧版繁体默认说话者名称的判断结果与原标准答案一致，同时兼容新的简体名称。

## 测试版使用说明

1. 新录一段中文会议，或导入已有中文音频，查看最终逐字稿是否为简体。
2. 整理会议记录，检查标题、摘要、待办、待确认问题和提问回答的中文输出。
3. 导出 Markdown、Word 或 PDF，核对正文、标签和字体。测试已有会议时，先按需要重新转录或刷新记录。

当前启动供手动体验的是 DEBUG 测试版，默认不读取已保存的真实 API 密钥。录音和本地转录可以测试；依赖已保存 API 密钥的整理功能暂受此限制。
